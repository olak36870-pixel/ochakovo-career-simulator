Проект «Очаково: путешествие по профессиям» 

Интерактивный мобильный карьерный симулятор для привлечения молодых специалистов (18–26 лет) на оплачиваемую летнюю практику в пиковый сезон (март — сентябрь).

Технологический стек
* Движок: Unity 
* Язык программирования: C#
* Особенности реализации: Полное отсутствие покадровых анимаций. Динамика реализована с помощью UI-трансформаций и динамической смены статических спрайтов для оптимизации производительности.

---

Игровой процесс и структура
Проект представляет собой экспресс-тур по ключевым цехам завода под руководством маскота — Мастера Очакова:

1. Экран 0: Стартовая заставка — вовлечение и приветствие («Погнали!»).
2. Уровень 1: Цех контроля качества — механика «Тайминг-клик» (исторический контекст: Олимпиада-80).
3. Уровень 2: Инженерный Цех — механика «Быстрый ремонт» (исторический контекст: ПЭТ-революция 1994 г.).
4. Уровень 3: Склад и Логистика — механика «Карточный свайп-инспектор» (управление пиковыми нагрузками).
5. Финал: HR-Конверсия — подсчет XP, присвоение карьерного статуса и переход к форме подачи заявки на практику.
